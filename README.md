## 📌 Featured Project · Proyecto Destacado

### 🤟 Sign Language → Text & Speech Translator

A real-time computer-vision system that recognizes sign language gestures and converts them into text and spoken audio — built with accessibility and digital inclusion in mind.

| Component | Technology |
|---|---|
| Language | Python 3.12+ |
| Computer vision | OpenCV |
| Hand/body detection | MediaPipe Holistic |
| Numerical processing | NumPy |
| Neural network | TensorFlow + Keras |
| Model training | Scikit-learn |
| Text-to-speech | Edge-TTS |
| Interface | PySide6 / CustomTkinter |
